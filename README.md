# Order Processing Platform

Microservices practice project (FastAPI, Postgres, Kafka, Redis, Docker, Kubernetes, AWS).

## Run everything
    docker compose up --build

Order service docs: http://localhost:8001/docs

## Run tests (no Docker needed)
    cd services/order-service
    python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
    pip install -r requirements-dev.txt
    pytest

## Migrations (Alembic)
Run from `services/order-service` (needs DB up: `docker compose up -d order-db`):

    alembic upgrade head                                  # apply all
    alembic revision --autogenerate -m "add xyz column"   # create after editing models.py
    alembic downgrade -1                                  # roll back one step
    alembic history                                       # list migrations

Always read an autogenerated migration before committing it.
